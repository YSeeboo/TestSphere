📋 选择验证方式：

方式 1 - 自动验证脚本（推荐）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  cd backend
  python3 verify_jwt_fix.py

  预期：至少前 4 项测试通过 ✓


方式 2 - 手动快速检查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  # 1. 检查 .env 文件中的 SECRET_KEY
  cat backend/.env | grep SECRET_KEY
  
  ✓ 应该显示 64 位十六进制字符（256位强度）
  ✓ 不应该是 "09d25e094faa..." 或其他示例值

  # 2. 检查 config.py 已移除默认值
  grep -A3 "SECRET_KEY:" backend/app/core/config.py
  
  ✓ 应该看到 Field(...) 而不是 Field(default=...)
  ✓ 应该有 min_length=32

  # 3. 检查安全验证器存在
  grep "validate_security_settings" backend/app/core/config.py
  
  ✓ 应该找到该函数

  # 4. 检查 .env 在 .gitignore 中
  grep "\.env" .gitignore
  
  ✓ 应该找到 .env 配置


方式 3 - 完整功能测试（需要依赖）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  # 前提：已安装依赖（poetry install 或 pip install）
  
  # 测试 1: 正常启动（应该成功）
  cd backend
  uvicorn app.main:app --reload
  # 看到 "Application startup complete" 后按 Ctrl+C
  
  # 测试 2: 使用不安全密钥（应该失败）
  export SECRET_KEY="09d25e094faa6ca2556c818166b7a9563b93f7099f6f0f4caa6cf63b88e8d3e7"
  uvicorn app.main:app
  # 应该看到 "检测到不安全的 SECRET_KEY" 错误
  unset SECRET_KEY
  
  # 测试 3: 缺少 SECRET_KEY（应该失败）
  mv .env .env.backup
  uvicorn app.main:app
  # 应该看到 "Field required" 错误
  mv .env.backup .env

  问题：缺少 .env 文件
  解决：cp .env.example .env
       然后生成新密钥：python -c "import secrets; print(secrets.token_hex(32))"
       
  问题：pydantic 模块未找到
  解决：这是正常的（还未安装依赖）
       基础验证（前4项）通过即可
       
  问题：需要重新生成密钥
  解决：python -c "import secrets; print(secrets.token_hex(32))"
       或：openssl rand -hex 32
